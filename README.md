# ONG Esperança

Projeto educacional desenvolvido na disciplina de Desenvolvimento Front-End para Web.

A aplicação simula o site de uma organização da sociedade civil e utiliza HTML, CSS e JavaScript.

## Funcionalidades

- Navegação em SPA
- Templates dinâmicos
- Validação de formulário
- Persistência com localStorage
- Modal e notificações
- Layout responsivo
- Integração com biblioteca externa
- JavaScript modularizado

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Git e GitHub
